# Puzzle Design — 谜题设计与依赖图（开发者文档）

## 0. 设计原则

1. **每题五要素**：有逻辑 → 可发现 → 可推理 → 可验证 → 有反馈（验证 = 明确的成功/失败反馈 + 解锁内容）。
2. **谜题即叙事**：所有钥匙都来自两人的故事；解谜 = 重走故事。
3. **多路径**：每个门有多条线索来源（≥2），任意一条足以推出答案；不依赖唯一点击顺序。
4. **门是"答案锁"不是"顺序锁"**：知道答案即可从任何入口（URL 直达 / 终端 / 页面表单）通过。
5. **软提示**：每门 3 档提示（方向 → 线索位置 → 接近答案），触发条件：失败 2 次出现"提示"按钮；搜索框彩蛋可提前解锁提示。
6. **无死路**：Red Herring 必须可在站内得到解释；所有 404 都是风味文本 + 出路；答案永不因浏览器/移动端/刷新而不可达。
7. **不过度加密**：全站仅用 Morse、Base64、XOR（伪加密）、FNV-1a（答案哈希防剧透）、一处 ROT13 彩蛋。

## 1. 阶段总览（玩家旅程）

```
S0 普通浏览 ──► S1 发现异常 ──► S2 第一道门(项目页) ──► S3 档案解密(关服夜)
                                                   │
                     S6 交接终局 ◄── S5 握手协议 ◄──┴── S4 系统面板(灯塔全貌)
```

| 阶段 | 玩家看到 | 玩家做什么 | 获得什么 | 进入下一阶段 |
|---|---|---|---|---|
| S0 | 一个普通的旧个人站 | 随便逛 | 无 | 注意到下面任一异常 |
| S1 | 心跳日志 / 自动草稿 / robots.txt / 搜索彩蛋 | 意识到"这个站在等人" | 弱异常感 + /old/ 入口 | 进入 /old/ 找到项目门 |
| S2 | 2022 年老版网站 + 成员登录门 | 跨页拼出灯塔岛坐标 | RE:LIGHT 项目页全貌（萤火存在） | 档案索引里的加密文件 |
| S3 | 加密文件 + "密码规则：我们第一次见面那天" | 拼出相遇日期 | 关服夜聊天记录（情感载荷①） | beacon.conf v2 → /system/ 路径与 PIN 规则 |
| S4 | 灯塔控制面板（PIN 门） | 算出"关服到点灯"天数 | 面板：倒计时/蜜罐记录/告别邮件（情感载荷②） | 面板里的握手终端 |
| S5 | 三题握手（灯语音频/编号/日期） | 综合全程线索 | 两封信（情感载荷③：全部真相） | 接灯选择 |
| S6 | 终局页 | 用 ●●—●● 回应灯语 | 全站状态永久改变（守灯人模式） | 通关；彩蛋层开启 |

## 2. 谜题明细

### G1「老地方」— 项目页成员门（S2）

- **门**：`/old/relight/` 成员口令输入框（placeholder："X,Y"）。
- **线索（3 条独立来源，任 1.5 条可解）**：
  - A（图库）：图片《灯塔岛看月亮》角落有褪色手写体坐标 `621,621`（视觉谜题）；
  - B（游戏收藏）：归墟OL 卡片"常用挂机点：(621, __) 别问"，补全需要 A 或 C；
  - C（博客《三年前的今晚》）：文中写"岛的位置我记在别处，两个数字一模一样，像某种预言"——提示"X=Y"+ 需从 A 拿数字。
- **答案**：`621,621`（规范化后比对数字串 `621621`）。
- **验证/反馈**：成功 → 页面展开项目 wiki（成员表、任务板、档案清单）；失败 2 次出提示。
- **指向**：档案清单列出 `chat-2019-06-21.txt.enc` 等 → S3。
- **提示**：①"两个来源各拿半张地图试试图库和游戏页" ②"图库那张月亮照片放大看角落" ③"六百二十一，逗号，六百二十一"。

### G2「我们第一次见面那天」— 档案解密（S3）

- **门**：`/archive/` 文件浏览器中的 `.enc` 文件，打开弹出口令框。
- **线索**：
  - 主：解密后可见的 `note-to-future-me.txt`（本文件不加密，位于档案根）："密码规则很简单：我们第一次见面那天。格式和文件名的日期一样。"；
  - 相遇日期的 3 个来源：博客《八年前的今天》（明写 2014-11-08 雪祭）、/old/relight/ 成员表（萤火 4097 加入日）、/legacy 风格论坛帖存档《新手求组，沉舟服》（2014-11-08）。
- **答案**：`20141108`（接受 `2014-11-08`、`2014.11.08` 等变体）。
- **验证/反馈**：FNV-1a(answer) 命中 → XOR 解出明文并渲染；错误 → "解不开。密钥不对。"
- **奖励**：`chat-2019-06-21.txt.enc` = 关服夜完整聊天记录（含 ●●—●● = "在" 的定义——S6 伏笔）；`beacon.conf.v2.enc` = 系统面板路径 `/system/` + PIN 规则。
- **指向**：S4。
- **提示**：①"不加密的那张便签在档案根目录" ②"博客里有一篇每年 11 月 8 日都会想起来的文章" ③"八年前的那篇：《八年前的今天》"。

### G3「从熄灭到重新点亮」— 面板 PIN（S4）

- **门**：`/system/` PIN 输入。
- **线索**：
  - beacon.conf.v2（G2 奖励）："pin = 关服那天，到 beacon 重新点灯，隔了几天"；
  - 关服日 2019-06-21（全站多处：博文、公告存档、聊天记录）；
  - 点灯日 2023-06-21（beacon.log 首条 `2023-06-21T21:00 beacon lit`；博文《网站的小自动化》暗合）。
- **答案**：`1461`（365×4+1，含 2020 闰日）。**本解为日期算术题，站内 /search/ 输入 `daycount` 提供内置天数计算器彩蛋（防手算错误）**。
- **验证/反馈**：成功 → 控制面板全开。
- **奖励**：倒计时（2026-10-01）、蜜罐信号记录（2026-06-21 ●●—●●）、2020 告别邮件全文（碎片 F3）、握手终端。
- **提示**：①"beacon.log 的第一行是哪天？" ②"从 2019-06-21 数到 2023-06-21，小心闰年" ③"365×4 再加一个 2 月 29 日"。

### G4「握手协议」— 三轮问答（S5）

终端输入 `handshake` 开始。三轮独立作答，答错不回退。

| 轮 | 题 | 谜题类型 | 线索 | 答案（接受的等价形式） |
|---|---|---|---|---|
| R1 | 播放一段灯语音频（WebAudio Morse），问"它在喊谁？" | 音频分析 | 音频即国际摩斯 `CQ`；S1 阶段 beacon.log 的 `sig=` 字段拼接同样是 `CQ CQ DE RX4098 K`；站内终端 `morse` 工具可播放/解码任意文本 | `CQ` / `cq` / `-.-. --.-` |
| R2 | "我在等的那个编号是多少？" | 跨页数字 | /old/relight/ 成员表（萤火 #4097）；聊天记录里"比你早四秒注册" | `4097` / `萤火` / `firefly` |
| R3 | "最后一次收到回信是哪天？" | 日期关联 | /system/ 蜜罐记录 2026-06-21 23:12；与关服日同月同日的规律 | `20260621` / `2026-06-21` |

- **验证/反馈**：每轮即时判定；全对 → 排队的信件解锁，`/relight/` 开放。
- **提示**：R1①"火腿无线电里最常用的呼叫是什么" ②"把 beacon.log 每行结尾的 sig 片段拼起来" ③"三个字母不到：CQ"。R2/R3 类推（见 master-solution）。

### G5「回应」— 接灯（S6，无失败态）

- `/relight/` 读完全部信件后出现"回应灯塔"交互：以 短/长 两个按钮敲出 ●●—●●（短短长短短），或直接输入"在"。
- 成功 → keeper 状态：全站改变（站标常亮、留言板出现萤火 2026 条目、首页公告、404 文案、终局页）。
- 容错：敲错可无限重敲；3 次失败后允许直接键入"在"。

## 3. 发现向量与软提示系统

**S1 异常入口（至少 5 条独立路径）**：
1. 首页状态栏"最近心跳：3 小时前"→ 链接 `/logs/`；
2. `robots.txt`（Disallows /logs/ /system/ /fragment/ /old/relight/ + 一行注释）；
3. 博文《网站的小自动化》提到"心跳"；
4. 搜索框输入"萤火/归墟/relight/4097/在"的彩蛋回应；
5. webring 邻居留言（留言板 2023 条目："站长的 robots.txt 是不是写错了 lol"）。

**全局帮助层**：`/search/` 彩蛋词解锁提示；每门 3 档提示；终端 `hint <门id>`；`/system/` 面板有"帮助"窗口列出全部门的当前状态。

## 4. Red Herrings（全部可在站内解释，无死路）

| 红鲱鱼 | 表面暗示 | 站内解释 |
|---|---|---|
| `/tmp/pcap-test.pcap`（hexdump） | "流量里藏着秘密？" | 打开后注释：白砂留下的抓包测试，无价值，"留个念想" |
| `/backup/config.js` 里 `ACCESS_TOKEN=***` | 隐藏凭据 | 行内注释：2023 年图床 token，"早失效了，别试" |
| 服务器日志大量 502 | "被攻击？" | 博文+日志注释：家宽不稳，"电信师傅上门三次" |
| 首页计数器停在 1314520 | 谐音梗暗示 | 留言板自嘲：站长手写的假计数器，"改这个数的手艺还停留在 2010" |

## 6. 源码层线索（深层，非主入口）

- HTML 注释：每页页脚一句任霄口吻注释（如首页 `<!-- 本站没有秘密。（有） -->`）；/old/ 内一处 ROT13。
- `data-arg` 属性与 `window.__RX__` 调试对象（包含 stage，不含答案）。
- `robots.txt` / `sitemap.xml`（隐藏页不列，`/backup/` 故意列入）。
- `manifest.webmanifest`、404.html、构建产物中的 `/.well-known/` 彩蛋（`humans.txt` 写人物小传）。
- 真实 PNG 的 tEXt 元数据块（图库《灯塔岛看月亮》副本 PNG 带 `Description` 坐标注释——图片查看器属性可见）。
- 音频：终端 `morse` 命令 + `/tmp/signal-test.wav`（构建时生成的真实 WAV，内容同为 CQ）。

```jsonc
{
  "gates": { "g1": false, "g2": false, "g3": false, "r1": false, "r2": false, "r3": false },
  "keeper": false,
  "found": ["logs", "old", "robots", "konami"],   // 发现类成就（非门）
  "guestbook": [ /* 玩家自己的留言（本地） */ ],
  "visits": 3,
  "hintsSeen": { "g1": 2 }

```

- 刷新保留；`storage` 事件跨标签同步；提供终端命令 `reset`（带确认）重置全部进度。
- 站点 chrome 依进度分级变化（灯图标：灭 → 半亮 → 亮 → 常亮[keeper]）。
