## 3. 走查中发现并修复的缺陷（回归测试已补）

| # | 缺陷 | 根因 | 修复 |
|---|---|---|---|
| 1 | 全站客户端脚本未执行 | `<script type="module">` 上的多余 `defer` + DOMContentLoaded 时序（内嵌浏览器差异） | 移除 defer；boot 改 readyState 自适应启动；每个 init 独立 try/catch |
| 2 | 门通过但内容不注入 | 内容载荷加密时缺 `MARKER` 前缀 | layout 统一 `MARKER + html`；测试新增"产物全部载荷可解出 MARKER"回归项 |
| 3 | G2 日期变体解不开 | decryptEncFile 未规范化 | 统一走 normalizeAnswer(digits) |
| 4 | G5 终局页空白 | 敲击答案未持久化 / 大小写不一致 | 敲击成功即 `setGate('g5', seq.toLowerCase())` |
| 5 | 404 文案不切换 | `data-404-variants` 的 dataset 键以数字开头非法 | 改名 `data-text-variants` |
| 6 | beacon.log 泄漏等待对象 | 心跳行明文 `waiting=4097` | 改为 `waiting=####`（叙事上更合理） |
| 7 | .enc 明文含开发注释 | 【密文载体】行混入玩家可见内容 | 删除 |
| 8 | 搜索彩蛋词/终端提示明文可读 | 触发词与提示直接写进客户端 JS | b64 混淆（与页面提示同级别） |

## 4. 已知边界（非缺陷）

- 无 JS 环境（noscript）：公开层完整可读；门不可解（ARG 常态，README 已注明）。
- `file://` 直开：模块与 localStorage 受限，README 要求经 HTTP 预览。
- 真实时间越过 2026-10-01：倒计时组件切"窗口已过 · 灯仍亮着"，全部谜题仍可解（已在 UI 验证逻辑）。
- 极小众答案输入（如 `ssLss` 手打带大写）在 g5 文本通道不匹配——主路径（敲击/「在」）均覆盖。
