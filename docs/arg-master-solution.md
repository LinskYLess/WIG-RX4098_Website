## 2. 逐门详解

### G1「老地方」

- **解法逻辑**：/old/relight/ 门上写"口令是老地方的坐标（X,Y）"。"老地方"的定义在聊天记录与博文中反复出现=灯塔岛。坐标的三处来源（见速查表）。玩家最少看 1 张图即可过；细心者会用两处半坐标互证。
- **触发条件**：进入 /old/（5 条 S1 向量任一）→ 页脚链到 /old/relight/。
- **解锁内容**：RE:LIGHT wiki：立项 README（2019-08-11）、成员表（萤火 #4097 离线 / RX4098 在线 / 白砂 已移除 / Momo 退隐 / root919 退圈）、任务板（冻结 2020-09-12）、档案索引（指向 .enc）。
- **剧情对应**：第一次"看见"萤火——一个真实存在过的人。
- **常见误区**：①输"灯塔"/"lighthouse"（岛名≠坐标——门 placeholder 是 X,Y，提示 1 会点破）；②把 4097/4098 当坐标；③以为要去源码找密码（源码层无 G1 答案）。
- **规范器行为**：剥除非数字字符后比对 `621621`；输入 `621，621`（全角逗号）亦通过。

### G2「我们第一次见面那天」

- **解法逻辑**：`note-to-future-me.txt`（未加密、档案根目录、列表页用"必读"标记）给出规则与格式提示（YYYYMMDD，"和文件名的日期格式一样"——`chat-2019-06-21.txt.enc` 即示范）。日期本身在博文《八年前的今天》明文出现两次。
- **技术**：`.enc` = Base64(XOR(UTF-8 明文, UTF-8 密钥))。前端验证：FNV-1a(规范化输入) 与内建哈希比对，命中后用输入作密钥解密。密钥 = `20141108`（6 位重复填充）。
- **解锁内容**：①`chat-2019-06-21.txt.enc`：关服夜 20:00–23:59 聊天记录（时钟塔→灯塔岛→强制下线；含"●●—●● = 在"的定义与"下次在线 老地方"）；②`beacon.conf.v2.enc`：/system/ 路径 + PIN 规则 + 蜜罐说明。
- **剧情对应**：情感载荷①——玩家亲历最后一天。
- **常见误区**：①输关服日 `20190621`（那是 G3 的原料不是 G2 答案——提示 2 会纠正到"八年前的今天"）；②输 2014-11-08 但格式带横杠（规范器放行，无虞）；③对着 `.enc` 文件名猜"文件名就是答案"（文件名是日期格式**示范**，值不同）。

### G3「从熄灭到重新点亮」

- **解法逻辑**：conf.v2 原文：`# pin = 关服那天，到 beacon 重新点灯，隔了几天。别怪我出算术题，我只是怕随便什么人都能进来。` 关服日：博文/公告存档/聊天记录（2019-06-21）。点灯日：beacon.log 首条（2023-06-21T21:00 beacon lit, mode=quiet）。365×4+1（2020 闰）= 1461。`/search/` 输入 `daycount` 弹内置计算器（防手算错）。
- **解锁内容**：/system/ 面板：BEACON 状态窗（seq、心跳、**倒计时至 2026-10-01**）、QUEUE（排队的自动草稿列表——点开可见 6 条"给萤火的话"）、HONEYPOT（2026-06-21 23:12 捕获 ●●—●● 签名记录）、MAIL（2020-10-03 告别邮件全文=碎片 F3）、TERMINAL。
- **剧情对应**：玩家此刻明白——这不是监控，是一台等人的机器；且它有了限期。
- **常见误区**：①算成 1460（忘 2020-02-29——计算器彩蛋就是为此）；②从建站日 2022-04-05 起算（那是网站生日，不是点灯日；提示 2 指向 beacon.log 首条）；③输"4年"。

### G4「握手协议」

- **R1**：面板"开始握手"→ 播放灯语（WebAudio，标准国际 Morse，字母 C 与 Q，播放 3 遍）+ Canvas 波形（视觉等价路径）。问："它在喊谁？"——火腿用语 CQ = 呼叫任意电台。S1 埋的 beacon.log `sig` 字段逐行片段拼起来正是 `CQ CQ DE RX4098 K`（呼应闭环）。站内终端 `morse -play CQ` 可随时复习。
  - 误区：输"SOS"（那是 /tmp/signal-test.wav 的内容差异彩蛋：该文件其实也是 CQ——不，两者一致都是 CQ；想找 SOS 的玩家会被波形图纠正）；输"萤火"（那是 R2）。
- **R2**："我在等的那个编号。" 成员表、聊天记录（"比你早四秒注册的是我，让让你"）、游戏卡（4098 旁边一行小字"我前面那个号"）。
  - 误区：输 4098（等的是别人）；输"白砂"。
- **R3**："最后一次收到回信是哪天？" 蜜罐记录明示 2026-06-21 23:12；且与关服日 6-21 同月同日是叙事 rhyme，玩家哪怕没细读记录也能从"七周年"语境推出。
  - 误区：输 2020-10-03（那是萤火**离开**的日子，不是**回信**——题面"回信"是关键）。
- **解锁内容**：/relight/ 三封信（见 §3）+ 全站进入终局前夜状态。
