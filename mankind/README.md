# 给人类玩家的一封信

你好！我是 Linskyless，本项目的作者。感谢你找到这儿！我只是在这儿说点闲话而已。

本项目完全由 AI 构建，包括故事设计，谜题设计和网站开发，我只参与了项目方向、部署和管理 Git 版本等部分任务（所以这部分可能会出差错）。本项目由 GLM-5.3/GLM-5.3 Flash 在最高推理模式下使用 ZCode 完成，消耗了约 88.87M Token。本项目完全使用 ZCode Start Plan 的 Token，总共花费 0 元。

我只是一名学生，完全没有学习过网页开发相关内容，完全没有做项目的经验。本项目只是我尝试使用 Agent 的试水项目，略显幼稚，请多包涵。因为学业压力，本人可能无法对本项目进行有效维护，还请见谅。

本仓库的 Prompt 在 [`Prompt.md`](./Prompt.md)。

好了，严肃内容到此为止，下面都是闲话了。

这个项目完全是我拍脑袋随便想出来的。一开始，我只是想试试 Vibe Coding，就开始瞎搞相关的东西。我想着，搞个项目玩玩吧，于是萌生了做个个人网站的想法。是的，一开始我只想做个个人网站+博客而已。

可是，真当我开始在 ChatGPT 的指导下开始尝试时，我却在 AI 奔涌的信息流、在破笔记本呼啸的风扇声中沉默。我不知道要做什么。具体地说，我不知道要给网站放什么东西--用什么头像，放什么标语，叫什么名字，放什么内容，写什么东西，做什么风格--我都不知道。我是一个无聊的人，我没什么爱好，我不知道要说些什么。

我是一个无聊的小镇做题家，是一个每次被人问理想/爱好都无话可说的人，是一个连社交媒体头像都不知道用什么的人。我心中好像有什么话要说，却不知道说什么。

于是那个计划就被我搁置了。我于是想着，嘿，之前玩过的某个 ARG/WIG （事实上，我也不知道怎么分类）还挺有意思的，为什么不试试做个这种东西呢？嘿，一个伪装成个人网站的 ARG 应该有点意思。

于是有了这个。

说实话，一开始我没抱信心，毕竟我什么都没准备，我只是随便写了个名字，然后让 ChatGPT 帮我生成 Prompt，我只想着 AI 随便搞个 Demo 我看看啥样，压根没对内容抱期望。可说实话，结果出人意料的还可以。

不同与那些恐怖/灵异/奇幻/犯罪性质的 ARG 作品，这个故事很平淡，或者你觉得很俗套，很无聊，可我还觉得挺有意思的。几个忙碌于生活的人，因为一个关闭的游戏，为一个虚妄的梦想努力，却在现实重力的牵引下轰然坠地。只剩一个念旧的人和一个不停的心跳。我觉得很浪漫，也许吧。

剧情很平淡，没有什么波折，而且各个页面里线索超级多，流程也很短，通过起来还挺容易。作为一个游戏而言，也许不够，但作为一个实验的 Demo 而言，我已经很震撼了。AI 确实写出了个 ARG 游戏，虽然他说的话一看就不是人说的，AI 味超级重，但这以及足以让我满意了。

实话说，这超乎我的想象了。我从来没有预想过这个 Demo 能做到这样。我之前只用过网页版的 AI，从Deepseek、Grok、Gemini、ChatGPT，到Qwen、Claude、Kimi、GLM，我也算涉猎颇广了。可我还是第一次用 Agent 软件做项目，没想到结果如此令我震撼。

没想到现在 Agent 这么发达了。

我忽然感觉自己好像跟不上时代了。这是我这辈子第一次有这种感觉，我一直觉得我还很年轻，我们新一代是时代的主人。可当 AI 的洪流在我身旁奔涌着、咆哮着，我却好像一个第一次见到纺纱机的纺纱工人，茫然无助了。时代的风口啊，他把 Nvidia 吹上天，把 OpenAI 吹上天，把一切站在风口上的吹上天，可我却无能为力，像是几十年前见到别人乘着改革开放东风发达而无动于衷的我的父辈。

可这还不是全部。我用的还只是 Flash 而已，我远没看到当下 AI 的极限。可这还不是全部。这只是现在而已，谁知道几个月后 AI 又会进化成什么样子。

我不知道。

......

说的太多了。这里写了我凌乱的妄言，就这样吧。

总之，我亲爱的朋友，我亲密的人类同胞，感谢您看到这，真的很感谢。感谢你在一堆 AI 产物中找到我写的闲话，而且读完了！

祝你好运！
